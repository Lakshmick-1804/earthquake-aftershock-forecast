Method & limits

How this prototype works

What the app does

The page loads an official USGS Earthquake Catalog CSV feed (past day, week, or month), with a bundled USGS CSV snapshot as fallback. You can also import a USGS-format CSV file.

The selected earthquake becomes the mainshock. Observed rows after it are used to set a search radius, infer a spatial trend, and scale a simple aftershock count model.

Trained Random Forest v1.0

The active engine is a bundled regression Random Forest trained offline on a USGS monthly catalog. Its 90 trees are exported to JSON and evaluated locally — no API, backend, or network call is needed at runtime.

It predicts the expected count of M≥3 events in the selected window from magnitude, depth, elapsed time, Omori decay, early observed counts, and an inferred trend. The map still uses the transparent spatial kernel to distribute that count across 3 km cells.

Pi = 1 − exp(−N̂RF · wi)

Catalog-calibrated baseline

Switching the engine selector to the baseline uses the transparent ETAS-inspired formula instead. It applies an Omori–Utsu time decay, an anisotropic spatial kernel, and a productivity scale derived from observed M≥3 counts in the CSV.

Pi = 1 − exp(−N · wi)

Both engines produce a Poisson-style probability per 3 km grid cell and an expected count, not a statement that an event will occur.

What is deliberately absent

  • The Random Forest is a compact teaching prototype, not an operationally validated forecast system.
  • The holdout comparison is one time-ordered split of one monthly catalog, not an accuracy claim or regional generalisation test.
  • For a changed start time, only catalog rows at or before that time are used; later rows are excluded.
  • The relief section does not dispatch help, collect personal data, or send requests to any agency.
  • Region coordinates and the inferred fault trend are approximate, not authoritative hazard geometry.

What the full system should add

A production system would ingest real-time catalogues and waveforms, train and validate a model against held-out sequences, publish calibrated uncertainty, and connect relief features to official, moderated service APIs.

Use this tool to explore relative patterns in a CSV catalog, not to issue alerts or make safety decisions.
